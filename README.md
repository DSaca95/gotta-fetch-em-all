A simple JavaScript-based web application that fetches and displays Pokémon data using the PokéAPI.  
Users can browse Pokémon, view their stats, types, and images in a responsive interface.

## Features
- Real-time data from PokéAPI
- Dynamic DOM manipulation
- Clean code structure with modular functions
- Responsive design for mobile and desktop

## Technologies
HTML5, CSS3, JavaScript (ES6), PokéAPI
